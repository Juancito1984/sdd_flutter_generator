## 🇪🇸 Resumen en Español
Plugin oficial para automatizar la generación de arquitectura modular **SDD Mobile (Spec-Driven Development Mobile)** en Flutter con BLoC puro, repositorios (contratos/implementaciones), Material 3 y bootstrapped core (`lib/app/`, `lib/core/`, `l10n.yaml`, features iniciales `home` y `details` con rutas nombradas).

👉 Lee la documentación completa en español aquí: [README_ES.md](README_ES.md).

---

## 🇺🇸 English Summary
Official plugin to automate **SDD Mobile (Spec-Driven Development Mobile)** modular architecture generation in Flutter with pure BLoC, repositories (contracts/implementations), Material 3, and bootstrapped core (`lib/app/`, `lib/core/`, `l10n.yaml`, initial `home` and `details` features with named routes).

👉 Read the full English documentation here: [README_EN.md](README_EN.md).
