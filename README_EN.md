# SDD Flutter Architecture Generator 🚀 (English)

Official plugin for **Android Studio** and **IntelliJ IDEA** created by **Ing. Juan Pablo Gosalvez** (`com.nyk`).

**English Version** | [Spanish Version](README_ES.md)

This plugin automates Flutter project and module generation following the **SDD Mobile (Spec-Driven Development Mobile)** architecture methodology, featuring **pure BLoC**, strict layer separation (`data`, `logic`, `presentation`), repositories with contracts and implementations, and native **Material 3** integration with light and dark themes.

## ✨ Key Features

The plugin adds an action group in the IDE titled **`SDD Flutter Generator`** (accessible via right-clicking in Project View and inside the **New** menu):

### 1. 📂 `New SDD Flutter Feature...`
Generates a complete modular structure for a new feature with three core layers (clean empty classes without boilerplate logic):

```text
lib/features/[feature_name]/
 ├── data/
 │    ├── models/
 │    │    └── [feature_name]_model.dart
 │    ├── repositories/
 │    │    ├── contracts/
 │    │    │    └── [feature_name]_repository.dart
 │    │    └── implement/
 │    │         └── [feature_name]_repository_impl.dart
 │    └── services/
 │         └── [feature_name]_services.dart
 ├── logic/
 │    ├── [feature_name]_bloc.dart
 │    ├── [feature_name]_event.dart
 │    └── [feature_name]_state.dart
 └── presentation/
      ├── [feature_name]_screen.dart
      └── widgets/
```

### 2. ⚡ `New SDD BLoC (logic)...`
Generates only the 3 BLoC state files linked via `part` and `part of` inside the selected folder (e.g. `logic/`):

- **`[name]_bloc.dart`**: Extends `Bloc<[Name]Event, [Name]State>`.
- **`[name]_event.dart`**: Declares `sealed class [Name]Event {}`.
- **`[name]_state.dart`**: Declares `class [Name]State { const [Name]State(); }`.

### 3. 🏗️ `Bootstrap SDD Project Core...`
Initializes production infrastructure in a newly created Flutter project, automatically creating `home` and `details` features inside `features/` and linking named routes in `app_routes.dart`:

```text
├── l10n.yaml
├── lib/
 │   ├── l10n/
 │   │    └── app_es.arb
 │   ├── core/
 │   │    ├── utils/
 │   │    │    ├── extension_app.dart (context.idioma, context.theme, context.colorScheme)
 │   │    │    └── custom_date.dart (longDate, shortDate)
 │   │    └── widgets/
 │   ├── app/
 │   │    ├── theme/
 │   │    │    └── app_theme.dart (Material 3: lightTheme, darkTheme)
 │   │    ├── logic/
 │   │    │    ├── theme_bloc.dart (Dynamic ThemeMode management)
 │   │    │    ├── theme_event.dart
 │   │    │    └── theme_state.dart
 │   │    ├── routes/
 │   │    │    └── app_routes.dart (Named routes /, /home, /details)
 │   │    ├── app_bloc_providers.dart (ThemeBloc provider)
 │   │    └── app_root.dart
 │   └── features/
 │        ├── home/ (data/, logic/, presentation/)
 │        └── details/ (data/, logic/, presentation/)
```

## 🌐 Internationalization Setup (l10n) in Flutter

For the localization support generated by **Bootstrap SDD Project Core** to work properly, make sure your Flutter project's `pubspec.yaml` contains the following dependencies:

```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_localizations:
    sdk: flutter
  flutter_bloc: ^9.1.1
  intl: ^0.20.3

flutter:
  generate: true
```

*(Note: The `nested` package is not required, as `flutter_bloc` handles state provider lists natively).*

Then, run the following command in your Flutter project terminal to generate the localization classes (`AppLocalizations`):

```bash
flutter gen-l10n
```

## 🛠️ Plugin Requirements & Installation

### Compatibility Requirements
- **IDE:** Android Studio (2024.1 / Build 241 or higher, including 2025/2026/Canary) and IntelliJ IDEA.
- **Flutter SDK:** Flutter 3.13.0 or higher.
- **State Management:** `flutter_bloc` 8.1+ / 9.0+.

### Zip Installation Steps

1. Locate the compiled plugin package:
   - `build/distributions/sdd_flutter_generator-1.0.0.zip`
2. In Android Studio / IntelliJ IDEA, go to **Settings** (or **Preferences**) ➔ **Plugins**.
3. Click the gear icon (**⚙️**) at the top right.
4. Select **Install Plugin from Disk...**.
5. Choose **`sdd_flutter_generator-1.0.0.zip`**.
6. Click **Apply** and **Restart IDE**.

## 💻 Developer Build Instructions

```bash

cd sdd_flutter_generator

# Build and run tests
./gradlew test

# Compile the final distributable (.zip)
./gradlew buildPlugin
```
